Basis concepten van een LLM

Token

  • Token is een vectorieele voorstelling van een woord of stuk woord
  • Elk model bepaald op verschillende manier zijn tokens (# tokens bij GPT-5.5 is niet gelijk aan # bij Claude Fable)
  • Token bevat niet enkel tekst, maar ook context

Reasoning

LLMs kunnen niet stil nadenken. Ze bepalen het volgende token a.h.v. voorgaande tokens.

  • Reasoning is een onzichtbare beredenering die uitgeschreven is
  • Vaak niet zichtbaar bij closed weight modellen omwille van reverse engineering
  • Meestal niet permanent bewaard in de context
  • Vaak met een budget (om eindeloos denken te vermijden)

Gewichten van een LLM

Gewichten zijn de getrainde parameters (rekensommen) die de LLM doorloopt bij het processen van een prompt en het genereren van nieuwe tokens.

LLMs liggen tussen de 0.5B (miljard) en >3T (biljoen) parameters

Gewichten van een LLM

Quantization

Standaard zijn gewichten getrained met floating point 16-bit.

  • Bij Qwen3.8:27b heb je dus 2-byte * 27 miljard = 54 GB
  • Dit komt overeen met het geheugen dat je nodig hebt om het model te draaien (zonder context)
  • Quantization verlaagt de precisie van de gewichten (naar 8-bit, 4-bit, ...)

Context van een LLM

  1. Elk token in de prompt, output, reasoning*, tool-call telt mee bij de gehele context
  2. Elk token (vector) bestaat uit een aantal dimensies (bv. 5120 bij qwen3.8:27b)
  3. Elk getal in de vector heeft een grote (FP16, ...)

Een niet-geoptimaliseerde context van 128K bij qwen3.8:27b is dus 128.000 * 5120 * 2-bytes = 1.22 GB

Router

  1. Voordat er een token gegenereerd wordt is er een snelle run doorheen het hele model.
  2. De run bepaald welke neurons in de tussenlagen het meeste impact hebben.
  3. De router kiest de beste X neuronen. De rest wordt niet gebruikt.
